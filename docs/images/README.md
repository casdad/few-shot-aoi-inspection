# Generated demo images

Run `python -m scripts.generate_demo` with an authorized input image and model bundle
to create the following local artifacts:

- `demo_original.png`
- `demo_anomaly_heatmap.png`
- `demo_result.png`
- `demo_panel.png`
- `demo_result.yaml`

Generated pixels and receipts are ignored by Git. Review the input's redistribution
rights and the receipt for sensitive paths before publishing any result manually.
